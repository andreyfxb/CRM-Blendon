# AXION CRM

O **AXION CRM** é um sistema de gestão de relacionamento com clientes desenvolvido pela AXION SOLUTIONS, com o objetivo de centralizar contatos, organizar negociações e otimizar o acompanhamento comercial.

A plataforma permite gerenciar clientes, acompanhar oportunidades de vendas, organizar etapas do funil comercial, programar follow-ups e monitorar indicadores de desempenho por meio de um dashboard.

### Funcionalidades
- Cadastro e gerenciamento de clientes.
- Centralização de contatos de diferentes canais.
- Pipeline comercial com etapas de negociação.
- Controle de follow-ups e lembretes.
- Histórico de relacionamento com clientes.
- Organização de vendas e negociações perdidas.
- Dashboard com indicadores comerciais.
- Relatórios de desempenho e conversão.
- Preparação para integração com WhatsApp Business.

### Objetivo do projeto

Desenvolver uma solução tecnológica que facilite a gestão comercial, melhore o relacionamento com clientes e ajude empresas a tomar decisões mais estratégicas por meio de dados.
